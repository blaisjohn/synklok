# Synklok — Setup

**Synklok** is a macOS menu bar app that auto-syncs the RME M-1620 Pro D
sample rate to its MADI input.

## Source layout

```
Synklok/
├── project.yml                     # XcodeGen spec (regenerates Synklok.xcodeproj)
├── Synklok.xcodeproj/              # generated by xcodegen
└── Synklok/
    ├── SynklokApp.swift            # @main + MenuBarExtra
    ├── AppState.swift              # @Observable app state
    ├── Settings.swift              # UserDefaults-backed settings
    ├── LaunchAtLogin.swift         # SMAppService wrapper
    ├── Synklok.entitlements        # network.client = true, sandbox = false
    ├── Sync/
    │   ├── M1620Client.swift       # HTTP client for the device API
    │   ├── SyncEngine.swift        # poll loop + rate matching
    │   └── DeviceDiscovery.swift   # Bonjour browser
    ├── UI/
    │   ├── MenuBarView.swift       # popover content
    │   └── SettingsView.swift      # settings window
    └── Logging/
        └── Logger.swift            # ~/Library/Logs/Synklok/sync.log w/ rotation
```

## Build prerequisites

- Xcode 15+ (we developed against Xcode 26)
- Homebrew + [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Building

```bash
# (Re)generate the Xcode project from project.yml
xcodegen generate

# Open in Xcode and run (⌘R)
open Synklok.xcodeproj

# Or build from CLI
xcodebuild -project Synklok.xcodeproj -scheme Synklok -configuration Debug build
```

The metronome icon will appear in the menu bar. Click it for the popover.

## Bundle ID

`app.synklok` — matches the synklok.app domain.

## Logs

Logs live at `~/Library/Logs/Synklok/sync.log` (1 MB rotation, 5 archives kept).
Tail live: `tail -f ~/Library/Logs/Synklok/sync.log`

## Distribution (later)

Code signing + notarization for direct distribution requires the Apple
Developer Program ($99/yr). The build script is wired for `CODE_SIGN_STYLE: Automatic`
so once a Developer ID team is selected in Xcode, signing is handled.
