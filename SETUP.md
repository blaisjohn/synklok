# Synklok — Setup

**Synklok** is a macOS menu bar app that auto-syncs the RME M-1620 Pro D
sample rate to its MADI input.

## Source layout

```
Synklok/
├── project.yml                     # XcodeGen spec (regenerates Synklok.xcodeproj)
├── Synklok.xcodeproj/              # generated by xcodegen
└── Synklok/
    ├── SynklokApp.swift            # @main + MenuBarExtra
    ├── AppState.swift              # @Observable app state
    ├── Settings.swift              # UserDefaults-backed settings
    ├── LaunchAtLogin.swift         # SMAppService wrapper
    ├── Synklok.entitlements        # network.client = true, sandbox = false
    ├── Sync/
    │   ├── M1620Client.swift       # HTTP client for the device API
    │   ├── SyncEngine.swift        # poll loop + rate matching
    │   └── DeviceDiscovery.swift   # Bonjour browser
    ├── UI/
    │   ├── MenuBarView.swift       # popover content
    │   └── SettingsView.swift      # settings window
    └── Logging/
        └── Logger.swift            # ~/Library/Logs/Synklok/sync.log w/ rotation
```

## Build prerequisites

- Xcode 15+ (we developed against Xcode 26)
- Homebrew + [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

## Building

```bash
# (Re)generate the Xcode project from project.yml
xcodegen generate

# Open in Xcode and run (⌘R)
open Synklok.xcodeproj

# Or build from CLI
xcodebuild -project Synklok.xcodeproj -scheme Synklok -configuration Debug build
```

The metronome icon will appear in the menu bar. Click it for the popover.

## Bundle ID

`app.synklok` — matches the synklok.app domain.

## Logs

Logs live at `~/Library/Logs/Synklok/sync.log` (1 MB rotation, 5 archives kept).
Tail live: `tail -f ~/Library/Logs/Synklok/sync.log`

## Distribution

Testers get a Developer ID–signed, notarized DMG: no Gatekeeper warnings,
drag to Applications, done. Requires macOS 14+.

### One-time setup

1. **Xcode → Settings → Accounts** → `+` → sign in with the Apple Developer account.
2. Create a **Developer ID Application** certificate at
   [developer.apple.com → Certificates](https://developer.apple.com/account/resources/certificates/add)
   and choose **G2 Sub-CA** (not "Previous Sub-CA", which expires 2027-02-01).
   Upload a request made in Keychain Access → Certificate Assistant → Request a
   Certificate From a Certificate Authority (Saved to disk), then double-click the
   downloaded `.cer`. Check it landed: `security find-identity -v -p codesigning`
   - Certificates last ~13 months. **Renew yearly** the same way; `release.sh`
     signs by fingerprint with whichever valid certificate expires last, so old
     and new can overlap. Delete the old one from the keychain afterwards.
   - **Never revoke** a certificate that signed a shipped build — that stops
     those copies opening. Expired is fine; Apple's timestamp keeps them valid.
3. Create an app-specific password at [account.apple.com](https://account.apple.com)
   → Sign-In and Security → App-Specific Passwords, then store it for notarization:
   ```bash
   xcrun notarytool store-credentials synklok-notary --apple-id <apple-id-email> --team-id <TEAMID>
   ```
   It prompts for the password and keeps it in the login keychain.

4. **Sparkle update key** (for automatic updates). Already created on John's Mac
   under keychain account `synklok`; its public half is `SUPublicEDKey` in
   `Synklok/Info.plist`. **Back it up** — without it, installed copies can't
   be updated:
   ```bash
   ~/Library/Caches/Synklok/spm/artifacts/sparkle/Sparkle/bin/generate_keys --account synklok -x synklok-sparkle-key.txt
   ```
   On a new Mac, import with `-f`.

### Key backup

Both keys (Developer ID `.p12` + Sparkle key, with a README) live in an
AES-256 encrypted disk image on the NAS: `znas` → `home/Backup/Synklok/Synklok-Keys-Backup.dmg`
(made 2026-10-15; password kept offline by John). After renewing the
certificate, export the new one (Keychain Access → My Certificates → File →
Export Items → .p12) and make a fresh image — never stage key files in
`~/Desktop` or `~/Documents`, which iCloud syncs.

### Each release

Bump `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in `project.yml`, optionally
write `release-notes/<version>.html`, then:

```bash
scripts/release.sh
```

Output: `dist/Synklok-<version>-<build>.dmg` (signed, notarized, stapled), also
copied to `~/Documents/synklok-web/downloads/` with a regenerated
`appcast.xml`. **Publishing is a separate step:** commit and push synklok-web,
which deploys to synklok.app. Installed copies of Synklok check
`https://synklok.app/downloads/appcast.xml` daily and offer the update.

### First launch on a tester's Mac

- macOS asks to allow Synklok to find devices on the local network: **Allow**.
  If it was denied: System Settings → Privacy & Security → Local Network.
- Launch at login is a toggle in Synklok's settings.
