Synklok 1.0.3 for Windows

  • First Windows release. A system-tray app for Windows 10 and 11 that keeps the M-1620 Pro D's sample rate matched to its MADI input, like the Mac version.
  • Automatic updates. Synklok checks synklok.app once a day and asks before installing. Use Check for updates… in the tray menu, or turn automatic checks off in Settings.
  • Installs for your Windows account only; no administrator password needed.
