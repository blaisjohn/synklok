Synklok 1.0.2

  • Automatic updates. Synklok now checks for new versions and installs them in one click. Use Check for Updates… in the menu, or turn automatic checks on or off in Settings → General.
  • Copy diagnostics. Settings → General → Logs → Copy diagnostics copies a report you can paste into a message.
  • Sample rate in the menu bar. Optional, in Settings → General → Menu bar. A warning icon replaces the metronome if the M-1620 and MADI input stay out of sync.
  • App icon.
